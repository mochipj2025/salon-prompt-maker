# Image2.0 Prompt Maker

サロン・個人店向けに、Image2.0用の画像生成Promptを短時間で作る静的Webツールです。

「考えずに選ぶだけで、法的に安全で雰囲気のある画像Promptが完成する」ことを目指しています。

## 想定ユーザー

- リラクゼーションサロン、整体、ボディケア、美容サロン
- 個人店、カフェ、バー、小規模ブランド
- SNS投稿やnote見出し画像を作りたい人
- AI画像生成のPrompt作成に疲れている人

## 主な機能

- 用途選択とアスペクト比の自動指定
- 雰囲気、業種、人物の選択
- 店名、ブランド色、固定キャラの任意指定
- 実店舗写真を背景参照にするPrompt指示
- シンプル/詳細モード
- NG表現チェックと安全な言い換え
- 完成Prompt、日本語要約、注意点の出力
- コピー機能
- localStorage保存

## 使い方

1. `index.html` をブラウザで開く
2. 用途、空気感、業種などを選ぶ
3. 必要なら店名、ブランド色、固定キャラ、店舗写真参照を設定する
4. 完成Promptをコピーする
5. Image2.0に貼り付ける

詳しい説明は `guide.html` を参照してください。

## 公開方法

静的ファイルだけで動きます。

- `index.html`
- `guide.html`
- `app.js`
- `styles.css`
- `assets/`

GitHub Pagesなどにそのまま配置できます。
